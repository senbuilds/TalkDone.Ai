# TalkDone.Ai

[English](./README.md) | **简体中文**

**Talk, Done! 语音输入，自动整理。**
在任何输入框里开口说话，TalkDone 会去掉口头语和重复，保留你改口后的意思，把整理好的文字直接填进当前位置。

🌐 **官网：** https://talkdone.ai

## 为什么选 TalkDone

现在的语音输入，用户只能二选一：

| | 闭源云端产品 | 开源本地产品 | **TalkDone** |
|---|---|---|---|
| 价格 | 月费贵，价格不由你控制 | 免费 | **同类的几分之一** |
| 本机负担 | 轻 | 重：本地大模型吃内存和 CPU，用久了越来越慢、越来越卡 | **轻：重活在云端** |
| 质量 | 高 | 取决于电脑配置 | **高：自研训练的整理模型** |

TalkDone 用的是我们自己训练的整理模型，从一开始就为「高效运行」设计。正因为它省资源，我们才能在保证质量的同时，把价格降到很低。
